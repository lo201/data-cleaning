I looked through your zip. It’s a Python Tkinter desktop app (GUI.py) with Decision Tree, KNN, and Logistic Regression models on CSV data. Tkinter only runs as a window on your own computer, so it can’t be given a URL as it is. To get a link, you need a web version of the app.

Options:

  1. Streamlit (easiest, my recommendation). Your model files (CleanData.py, KNN.py, DecisionTree.py, LogisticRegressionModel.py) are plain Python and can be reused. You only rewrite GUI.py as a Streamlit page, with a sidebar for Home / Pre Processing / each model, and your PNG figures shown with st.image. Then:
    • Push the project to a GitHub repo, with a requirements.txt (pandas, scikit-learn, matplotlib, streamlit).
    • Go to share.streamlit.io, connect the repo, and pick the main file. It gives you a free URL like yourapp.streamlit.app.
  2. Flask or FastAPI. This gives more control but takes more work, since you need HTML templates. You can host it free on Render or PythonAnywhere.
  3. Hugging Face Spaces. Free, and it supports Streamlit and Gradio. It works well for student ML projects.
  4. Temporary link only. Run a web version locally and use ngrok or Cloudflare Tunnel to get a public URL while your computer is on.

Something to check first: a few files import api_client and user_storage (they show up in __pycache__), but those .py files aren’t in the zip. If your project needs them, include them.

Do you want me to convert GUI.py into a Streamlit app, ready to push to GitHub and deploy? I can also write the requirements.txt and deployment steps.
